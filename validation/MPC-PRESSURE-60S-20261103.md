# 原 Planner / MPC 60 秒单场景短测（2026-11-03）

按要求只测同一个高压力场景一次：模拟 60 秒 = 1800 tick（30 Hz），
Original Planner 与 MPC 各跑一场。离线确定性闭环，无游戏进程、无键盘输出。

## 1. 场景

`mpc-pressure-swarm-1`，种子 11：

- 28×16 合成房间；
- 6 个追击敌人；
- 每 18 tick 一发种子弹幕；
- 敌人每 45 tick 进行一次意图射击；
- 玩家 6 HP。

## 2. 运行

```powershell
.\bin\IsaacGamebot.exe --mpc-pressure validation/mpc-pressure-60s-20261103/mpc-pressure-60s.json 60 1
```

原始数据：`validation/mpc-pressure-60s-20261103/mpc-pressure-60s.json`。

## 3. 结果

| 指标 | Original Planner | MPC |
| --- | ---: | ---: |
| 模拟时长 | 1800 tick（60 s） | 1800 tick（60 s） |
| 掉血 | 1 | **1** |
| 死亡 | 0 | 0 |
| 清房 | 否（4 / 6 击杀） | **是（6 / 6 击杀）** |
| 输出伤害 | 185 | **240** |
| 射击 / 命中 | 180 / 55 | 151 / **72** |
| 平均规划 | 27.11 ms | 30.74 ms |
| 最大规划 | 45.76 ms | 58.50 ms |
| MPC 回退 | - | 0 |
| MPC 序列复用 | - | 1728 次 |

结论：

- 两者掉血和死亡相同（1 点、0 次），MPC 没有用生存换输出；
- MPC 多 2 个击杀并完成清房，输出高 55 点，命中数 72 vs 55；
- MPC 主动少打 29 发（151 vs 180），命中率更高；
- 规划耗时约为原 Planner 的 1.13 倍，未触发回退。

## 4. 复现性

90 tick 确定性探针通过（`deterministic=true`）；本次完整 60 秒只运行一次，
未用第二次完整运行做重复性声明。

## 5. 证据边界

这是合成 `Frame` 闭环，不是实机房间，也不是实机无伤成绩。60 秒是模拟游戏时间
（1800 tick @30 Hz），不是实机 60 秒录像；实机表现仍需要游戏内验证。
