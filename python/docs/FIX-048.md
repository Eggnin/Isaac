# 048：阶段追击配置与爆炸蜘蛛

依据 047 的 5 次原生伤害请求，继续推进机制计划 P3/P4。047 的两次长腿怪伤害和爆炸蜘蛛伤害已冻结成短时序，原始日志保留。

## 实现与边界

- 新增 engine_behaviors.py，行为配置明确限定引擎 v1.9.7.17.J460、类型 207、variant 0、Walk 阶段，并记录本机证据来源。原生两次命中前 target=0，旧的“必须有目标指针才建行走追击”未覆盖此情况。
- 单人只有一个可用玩家时，用该目标和当前实测速度建立候选路线相关的追击分支；保留原始直线/曲线实测轨迹。联机有明确远端目标时跟随该目标，目标未知时仅加软预警。
- 转向使用保守可能上界，不声称测出了完整 NPC 转向率；不在 Attack、未核实版本或其他 variant 套用该配置。207/1 尚未由这条原生配置覆盖。
- 爆炸蜘蛛 type 250 / variant 0 进入既有爆炸生命周期模型：生前预留可能爆炸范围，死亡与移除后短窗口继续保留。80px 是当前保守规划包络，并非声称测出了所有变体的精确伤害半径。

类型核对：[EntityType](https://wofsauge.github.io/IsaacDocs/rep/enums/EntityType.html)。行为判定依据本机 J460 伤前轨迹与请求，攻略仅作为线索；变体、阶段和目标归属不从怪物名字推断。

## 验证

85 项相关离线检查通过，包括真实追击样本、未知/远端联机目标、非适用阶段和版本排除、爆炸蜘蛛生前/死亡/移除生命周期，以及旧运动拟合和目标归属回归。

冻结片段：tests/regression_data/combat048.json。对照：records/validation/native048-replay-0.4.7.json 与 native048-replay-0.4.8.json。新模型在长腿怪转向案例伤前 12 帧已报告未来碰撞，旧版该帧报安全。新增危险后碰撞帧数上升不能理解为受伤变多，它表示不同模型的预测；也不能用改变后的移动意图推断实战一定无伤。

原生有界结果单列 records/validation/combat048-validation.json。源码固定 build/releases/048/source；程序 dist/IsaacExternalAssist048.exe。

单局 120 秒测试完成 7 次开门、1 次受伤；456,985 条回调完整，恢复成功。游戏约 0.831x；搜索 p50 33.52ms/p95 46.84ms，7 次方案过期拒绝，性能问题仍存在。未完成 Boss 房。

唯一伤害请求来自 292/0 可移动 TNT，带 DAMAGE_EXPLOSION 和 DAMAGE_TNT。其伤前约 80px 持续射击被旧模型报为安全，继续在 049 修正。不同随机种子不可直接比较受伤率。
