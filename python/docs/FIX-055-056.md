# 055 / 056：用速度优势主动带怪

用户指出：对于追击速度低于玩家的近战怪，应该先突破包围，把怪群带在身后，保持移动并向后攻击；靠近角落应提前选择有退路的方向，不能一直等近身后才躲避。本轮新增 engine_kiting，由 planner 调用，动作碰撞检查仍在 engine_search。

## 进入条件与路线

把可用玩家位移速度与每个已确认本地追击体的速度比较。敌速包含当前测量，以及惯性模型在持续追击下的速度估计，不能只比较怪物刚起步时的低速。至少保留 15% 的估计余量；日志同时记录玩家实际速度、可用速度、敌速及比值。

仅当接触敌人都有明确的本地追击模型时启用。未知联机目标和软预警不能当成已确认追击；普通射手、未知怪物或没有足够速度优势时沿用原有规划。弹幕、爆炸、地形等仍在全量动作检查中。

从实际可通行区域构造向内留出转弯空间的闭环，逐边验证，不能穿墙或把窄死路当成环线。进入环线的连接也必须可通行。候选目标是持续沿环线前进，不依赖自动走门、拾取或探索。

沿环线的进展只允许投影到附近可连续到达的弧段；跨到对面边不能凭空获得半圈进展。首个 4-tick 分段也必须推进，防止每次把移动推迟到预测末尾。

## 与攻击、碰撞的关系

风筝期间不为静止射击切回原地保持，移动和射击输入继续分开执行，允许移动中向后攻击。风筝进展排在射击站位和舒适距离之前。

实际身体/弹幕几何碰撞、完整延迟包络安全及近期保护窗仍先比较。在延迟包络重叠已不可避免时，风筝进展位于一般脱围建议和额外未来包络暴露之前。因此这是显式目标排序改动，不应描述为排序完全没变。模型预测不是严格无伤证明。

## 056 修正

- 记住最近 60 原生帧内多次自由移动测得的速度，用第三高观测而非单个峰值作为补充容量；受伤冷却、地形限制等不合格样本不补入。转弯减速不会立即抹掉已观测速度余量，过期后失效；动作运动模型本身未因此加速。
- 沿当前环线仍在推进时保持绕行方向。只有连续至少 30 帧没有向前进展，且另一个方向有明确优势时才重选，降低带怪过程中突然回头。
- gathering_pack 成为独立目标：比较 16 个可直达的环线入口，使用现有全危险检查及随玩家路线变化的追击预测评价前 24 tick，选择集怪目标。已安全的入口保持到接近，预测出现碰撞则重新比较；这些探测是目标建议，实际带惯性的动作仍由主搜索检查。
- 到入口附近且怪群落在预计前进方向后方时，转入持续环绕。日志记录实际集怪目标、环线、方向、速度容量和怪群落后比例。

112 项不同的相关离线检查通过。新检查覆盖转弯减速后速度记忆、到期失效、仍在推进不反向，以及被包围开局的实际集怪目标。
