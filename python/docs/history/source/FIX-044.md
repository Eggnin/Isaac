# 044：跳起后失去攻击目标，不应停止避让

## 最新实测

043会话20261025-084847-8a6aa6/run-0001：1916次观察，6次受伤后在Widow房间死亡，6次开门切房（含初始空房）；无卡住超时/崩溃，恢复成功。游戏速度0.9971，规划中位35.31ms、最大68.76ms。6次受伤前相邻观测的按键比较均一致，暂未见这6次由按键未生效导致的证据。

接近的实体候选主要是二级蜘蛛215（前三次）、Widow100（第四/六次）和普通蜘蛛85（第五次）。这些是健康/冷却变化、邻近实体和时序证据，不是确认的原生伤害来源回调。

## 明确根因与修改

敌人跳起、碰撞状态变化后会暂时退出可攻击目标集。RoomMechanism虽标记dodging_residual_danger，却把“当前位置”交给走门/按钮用的导航函数。当贴墙角色位置无法连接保守导航图时，函数以no_safe_door_approach直接返回零移动，根本没有进行新的危险搜索。旧search报告还可能保留上一帧数值，不能据此断言每个停住帧都完成了避让规划。

044在这种状态直接调用危险规划器，不要求一个导航目标；保留原地形、边界恢复、危险体、碰撞和延迟约束。没有攻击目标也持续避让，但不射击、不拾取、不走门。诊断写evasion_mode=hazard_search_without_goal。

同时根据本局补齐：

- 二级蜘蛛215和滴答蜘蛛250的Idle/Walk阶段，保留其已观察到的原生target_position预约，沿用普通/大蜘蛛规则；不猜新的玩家位置。
- 二级蜘蛛Jump阶段保留原生目标点和走廊。记录中Jump第18帧首次观察到本次落地伤害，目标点从第16帧预约，提前2帧；这是本次记录下的保守估计，仍需更多实测。现有实体和通用跳跃危险分支均保留，没有推迟它们的碰撞检查。
- Widow Jump在第14帧后出现显著减速或低速时，额外保留当前已观察位置0.6秒的占位假设，防止仅按反向/减速速度外推，错误认为落地区域马上空出来。不把target_position=0解释为玩家坐标，也不声称该假设就是精确原生落点。
