# 042：射击几何、地形回退与重复受伤预警

基于040会话20261025-013409-ed6868的已有记录继续修改041；没有新游戏实测，不混用版本计算成功率。用户要求继续修改三处，原来“只处理测试/暂停战斗”的限制已被覆盖。仍不自行启动游戏、不使用Computer Use、不做视觉验证或全量测试。

## 1. 导航和瞄准共用发射与命中几何

shot_geometry.shot_intersections统一发射眼位、速度继承、目标线性拦截、弹丸半径和射程计算。实际瞄准使用观测玩家速度；导航评估未来停稳位置，明确假设速度为0，共用同一公式、目标观测与通道参数。导航仍检查实际射线地形、实体阻挡和爆炸距离。

发现普通泪弹以前被赋予8px area_radius，使擦边位置可能误报命中。现普通泪弹不再享有范围伤害容差。真实范围武器保留对应范围参数。严格命中线可能落在20px网格之间，因此在全体敌人路线不可达时尝试10px导航；只在找到实际路线时采用，移动仍在原像素地形上扫掠，不改变碰撞体积或危险采样。

## 2. 地形阻挡后的可解释回退

所有敌人射击路线均不可达时，仅普通无特殊效果泪弹、无同伴、房间无TNT的情况下，寻找原生已观测棕色便便的可达射击位置。目标是明确的grid_objective，NPC目标列表和HP不变，Decision.target不伪装成敌人。优先级结合到便便的路线和与敌人的距离，是清障尝试，不保证这一块便便清除后一定能解锁敌人路线。

仅为射线终点创建私有掩码，允许判断打到这块便便；实际walkable、shot_walkable和物理移动始终保持阻塞，直到原生状态变化。真正射击前再次核对射线首个阻挡确是目标棕色便便，保留石头/TNT/其他先行实体的拒绝规则。实际清障记can_attack_grid，不记敌人命中。无可处理障碍则记no_reachable_breakable_barrier，不随机强行移动或穿墙。

## 3. 用受伤时序定位具体遗漏

分析damage-events时间上下文，并保留最近危险只是候选、不能确认来源的边界。找到3局13条重复记录：普通Gluttony在Attack01第29帧出现所属激光、原生timeout=31，伤害观测发生在同一帧；此前23–27帧的决策却报告0预测碰撞。代码只处理variant1的另一种攻击，漏掉普通variant0的Attack01激光预警。

新增普通变体的提前激光通道预约。上下方向由动画确定；水平朝向未确认时保守预约两侧，不猜玩家目标。保留真实激光读取。没有把其余受伤归因为Gluttony，也没有下调延迟余量或碰撞约束。

CombatEvidence的受伤记录增加上一决策的预测碰撞、观察帧间隔、之前意图按键和当前引擎动作比较；跨房间不引用旧决策。一次按键不一致只记录证据，不直接判为输入故障。历史CombatEvidence有556次受伤，另一damage-events流有558条事件，口径不同，不相加成新局数。
