# 以撒外部辅助 0.3.0 核心整合版

适配本次重装的 v1.9.7.17.J460 / Steam build 22878971。只读引擎内存，在外部规划并输出正常键盘操作，不安装模组、不注入 DLL、不写游戏内存、不改变数值，不需要 REPENTOGON。

## 使用

先关闭其他版本的辅助窗口，再从桌面“以撒外部辅助”打开本版。标题应显示 0.3.0-external-core。

- 保持 Steam 登录，进入房间后点击开启或按 F6 开关；F7 关闭。
- Esc、暂停、换房或失焦时释放按键，保留启用偏好；恢复正常后继续。
- 默认关闭。清房交还控制，由你走门、选择道具。
- 默认游戏键位为 WASD 移动、方向键攻击；无需标记自己、队友、地图或武器。

## 0.3.0 穿墙／穿透、选敌与计算性能

读取当前引擎玩家的 128 位 TearFlags，分开处理穿墙和穿透。攻击、站位和全局导航共用发射通道规则；穿墙射线仍受房间墙壁约束，穿透不会让角色跨过障碍。不会把单颗随机效果眼泪的标志套给永久属性，也不会把玩家标志套给不明宝宝武器。

所有候选敌人比较可达射击位置和绕路距离，优先可达目标，再保留残血收尾、召唤怪优先级和目标保持；不再只按直线距离选中目标后才查路线。几何连线及射击位置成本批量计算，保留全部危险、原预测时长和候选路线数量。

124 项离线回归通过。同一现场冻结快照的预热规划中位数约 22.57ms，此前 0.2.9 记录约 40.7–40.8ms，减少约 45%；这是特定快照计算耗时，不是游戏 FPS。本次原生短测未取得前台控制，仅完成影子规划，未计作实战通过。详见 TEST-RESULTS-030.md。

## 0.2.9 障碍物旁原地停住

修复“攻击判定被石头挡住，选路却以为已经到位”的不一致。当前位置靠近障碍时，导航连接附近真正可达的网格并检查连接段，不再因最近网格被阻塞就丢掉绕路成本；不可达路线也不会被当作零成本。攻击站位评分同时考虑地形挡枪，保留穿过地形的武器类型例外。

来自当前大房间现场的冻结快照重放，由原地不动改为安全绕行第一步；110 项离线回归通过。没有重启或代打用户当前这局，尚无本版新的实机清房验证。详细证据与耗时见 TEST-RESULTS-029.md。

## 0.2.8 输入接收与战斗验证

修复中文输入法截获移动键的问题：辅助实际发送按键前，仅临时关闭游戏窗口的输入法；暂停、失焦、关闭辅助或清房释放控制时恢复原状态，不切换全局输入语言。原先已关闭的输入法不作改变。游戏明确暂不允许角色操作时释放按键，不误报为正常控制。

新增引擎键盘绑定/动作状态、OS 按键和输入法状态诊断；普通眼泪、宝宝和刀也进入战斗日志。相同规划中重复坐标的攻击位置评分使用精确缓存，不降低危险数量、检查频率或预测长度。

105 项离线回归通过。通过无 Computer Use 的原生房间短测：四个普通敌人无伤清房，血量 6→6 半心、16 颗眼泪，清房交回控制；规划耗时中位数约 30ms。该结果不代表 Boss、密弹幕或完整联机验证，详见 TEST-RESULTS-028.md。

## 0.2.7 运动单位与安全区域引导

敌人和弹幕的位移校准按实际间隔帧数计算，需两次方向一致、速度稳定的有效观测才应用。普通轨迹、瞄准目标、爆炸落点和跳跃/冲锋预留使用同一套预测速度；保留原始读取数据，避免误把单位校准当成敌人突然加速。地址被其他实体复用时重新拟合。

近处受到实际危险压力时，在碰撞、缓冲和退路等级之后，偏好逐步通往连通且未来有空间的区域。不会固定绕圈，也不为增加距离无限远离敌人；原地安全且可有效射击时可继续停留。地形和全部危险仍参与检查，墙边与窄路并非禁行。

旧内置版的逐项差异与尚未验证的引擎能力见 LEGACY-PARITY-AUDIT.md。没有宣称已读取全部隐藏状态或与内置版完全等效。89 项集中离线回归结果见 TEST-RESULTS-027.md；实机测试另行记录。

## 0.2.6 实际退路与射线遮挡

退路按实际位移方向计数：不同按键沿墙滑向同一走廊，不再虚增多条逃生路线。惯性导致的路线重合也去重，输入排列不影响方向数；墙边、墙角或窄路仍可用于紧急逃生，并非硬禁行。日志新增 safe_exit_inputs 与 distinct_clear_exits，便于核对按键数量和实际退路的区别。

普通眼泪的攻击、位置评分和导航使用相同的身体遮挡判断，避免停在被石肥仔或无敌身体挡住的射线上反复停火。导航会保留绕行射击机会；光束与穿透武器不套用普通眼泪的遮挡导航。石肥仔仍只是软身体障碍，不产生伤害预警。

普通全圆形危险的短期扫掠计算使用分量公式，保留全部危险、时间窗口和轨迹；复杂光束/圆环继续使用原几何，原计算可由 reference=True 对照。78 项离线回归通过，251 危险体模拟场景三次约 110–133ms；详见 TEST-RESULTS-026.md。尚无本版实战或完整联机验证，不能保证无伤。

## 0.2.5 回归修复与完整诊断

修复安全停留误触发和远距离偏好压过有效攻击的问题：必须有当前射击条件，并由上一帧实际命中评估确认，才启用特殊停留逻辑；敌人身体/弹幕/爆炸的真实危险与缓冲仍优先，但达到安全后允许移动到有效射程和射线上。

石肥仔作为 obstacle，仅提供低权重身体绕行成本，不再产生伤害预警或占据长期危险退路。已识别自爆怪与可接触爆炸弹使用保守的爆炸范围预留，而非仅软预警；这不表示活怪周围持续造成伤害。未知敌人的爆炸机制仍可能漏判。

修复无关连续激光冒认硫磺火尾段的问题；有精确主光束引用时按引用核对。蓄力武器只在当前有有效瞄准时释放，预蓄力沿用旧方向不再代表允许发射。

新增后台详细日志：受伤观测前约 3 秒的敌人与危险状态、控制按键、攻击拒绝原因、各方向评分、路线与退路评价、蓄力/发射/尾段阶段、本地延迟预算和读取错误。文件与轮换规则见 LOGGING.md。状态字段不会声称知道精确伤害来源。

圆形退路危险检查优化为分量与距离平方批量计算，保留全部危险与采样时刻；线段/圆环沿用原几何。离线对照与模拟耗时结果见 TEST-RESULTS-025.md，不代表游戏帧率。

## 0.2.4 多人目标与安全停留

追踪路径和激光眼预判优先使用已读到的玩家目标引用；目标未知时保留保守预测，不把猜测方向说成已确认。怪物瞄准队友也仍检查是否会打到自己，可能换目标的分支作为软预警。

原地松开方向键的路线计入惯性，并额外检查总计 40 个引擎帧的未来危险；满足缓冲、预警、逃生方向和长期退路条件时，允许留在安全射击位置，不只为增加距离而逃跑。末端出口同时考察缓冲质量，长期退路检查通向未来安全节点的连接段，避免只看节点安全却忽略中间穿过激光。

依据本机读取、计算及采样周期给危险几何增加延迟余量；发送前若决策已超出该时间预算，则释放旧控制等待新快照。网络 RTT 目前未核实，日志为 null，不能把这项本地余量称为网络延迟补偿。合并相同方向的续接段进行批量几何计算，没有截断危险列表；未测量实际加速幅度。

## 0.2.3 爆炸避让

已识别的自爆敌人按爆炸半径再加 28 像素预留站位，而非只按身体尺寸保持距离；攻击安全检查增加到爆炸范围外 24 像素，并检查预计命中时路线上的位置。敌人消失后短暂保留其最后位置的爆炸预留，以覆盖未采到死亡帧的情况。

实体炸弹从读到引信时就提供软预警，倒计时结束前 6 个引擎帧进入提前清场预留；己方炸弹也参与。投弹怪已生成的炸弹、带爆炸标记的抛射物继续按实体和落点处理。未知敌人的未出现投弹行为及未映射爆炸类型仍不能保证识别。

## 本轮避伤优先

路线先比较实际碰撞、危险缓冲、预警和退路，再考虑攻击；远距离站位是安全路线内的偏好，不会无限压过有效射击。敌人接触边缘以外预留 64–110 像素缓冲，高速敌人留得更宽；弹幕预留 20–40 像素，光束预留 24 像素。缓冲是路线偏好，不会把紧急逃生的唯一窄路封死。

站位优先接近武器有效射程的远端，并保留脱困方向；危险时允许离开射程。距离达到目标后不继续无止境远离，墙边仍可作为逃生位置。安全评分分档并提高反复转向代价，只在安全相近时偏好平稳移动；危险时仍可立即换向。不能保证零受伤，当前版本尚未实战验证。

## 核心整合

分段转向寻路、完整直行逃生路线、路线续接、末端脱困和长期退路；运动惯性/速度/位置积分校准；高速、转向、追踪、跳跃和冲锋预测。

地刺/按钮/地形与无害身体处理，激光前摇、移动/旋转/弯曲光束及圆环，地面危险、落点、爆炸金币和困难贪婪最终 Boss 等特殊预警。

多武器共用方向评分、移动后射击评估、射程/遮挡、补刀与召唤者优先；普通眼泪与持续激光分别计算命中。特殊武器蓄力、硫磺火完整尾段、刀飞行与按距离蓄力；莉莉丝 Incubus 起点、蓄力宝宝冷却和短松手释放；玄秘魔眼/标记光标等控制。

数学计算使用 NumPy 批量处理，不删掉怪物或子弹来减轻负担。预览地图只降低界面刷新频率，不降低规划检查频率；本轮没有测得性能提升结论。

## 边界与验证

完整源码对应和实现差异见 MIGRATION.md。部分机制使用观测校准或估计，不能将本版说成与原模组百分之百等效。在线玩家归属改按引擎 NetInputDevice 的本地标记自动识别，不默认房主、第一位玩家或控制器 0。已在当前对局只读核对：控制器 3 为远端、4 为本地；尚未验证完整联机战斗或换人场景。

本轮用户授权后由 Luna（低推理强度）运行离线回归测试与模拟耗时检查，结果和范围见 TEST-RESULTS-025.md 与 TEST-RESULTS-026.md。未启动游戏、发送真实按键或使用 Computer Use；不能据此保证无伤、真实联机表现或所有武器组合正确。
