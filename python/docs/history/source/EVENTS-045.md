# 045：测试期间全部Lua回调逐条记录

用户明确选择“所有回调逐条原样保存，包括每实体每帧更新”。本版不做采样、合并、轮换或数量截断；事件来自现有临时测试桥接，感知与角色控制仍为外部程序。没有自行启动游戏。

## 捕获范围

运行时枚举ModCallbacks，按ID注册全部可用回调，别名保存在目录中。安装的enums.lua有74个ID，实际运行以engine-events.jsonl头部目录为准。目录记录注册是否成功；注册成功不表示引擎一定会触发，例如本机将MC_LEVEL_GENERATOR注明为未启用。只能捕获引擎向Lua暴露且实际触发的回调，不等于所有未公开C++内部事件。

高优先级观察器在控制回调之前运行，并始终返回nil，不取消伤害/碰撞/AI，不覆盖输入或物品选择。逐条保存更新、渲染、输入查询、生成、移除、死亡、伤害、房间/楼层等回调。MC_INPUT_ACTION的原有数值/布尔契约保留。

每条有全局序号、回调ID/名称/别名、引擎帧、房间、楼层、时间和完整位置参数数量。nil参数有显式标记，布尔false不丢失；Lua整数以十进制字符串保留，避免64位标记经过JSON损失精度。模组self是Lua分发器插入的固定观察器对象，头部记录observer_mod，args保存原生回调参数。

“原样”针对回调调用和参数值。原生userdata不能直接写入JSON：保存对象表示、实体Type/Variant/SubType/InitSeed/Index/指针哈希及可读公开字段、位置/速度/动画等；EntityRef保存其Type/Variant和Entity；不透明对象明确标为opaque，读取失败标为read_error。移除对象只保留身份，不再读取Sprite。没有转储完整C++对象堆，也没有修改游戏内存。

捕获范围从临时桥接加载开始，到观察器请求结束并收到flush/close确认，或引擎PRE_GAME_EXIT为止。之后的强制进程清理不属于受控捕获范围。崩溃、写入失败或未收到结束证据时，不声称完整。

## 每局文件

| 文件 | 内容 |
|---|---|
| engine-events.jsonl | 全回调原始流，头部目录、每次调用、结束计数 |
| engine-damage-events.jsonl | 同一伤害回调记录的独立索引，含EntityRef、伤害量、标记、倒计时 |
| engine-event-status.json | 已见/已写数量、逐ID计数和错误状态 |
| damage-source-links.jsonl | 按帧、房间、楼层、角色种子关联血量/冷却变化 |
| engine-event-capture-summary.json | 结束确认、尾部校验和完整性结果 |
| evidence/damage-NNNN.json | 原受伤快照索引，追加引擎来源候选及关联证据 |

DamageFlag枚举和回调目录写入头部。主控制循环只解析小型伤害索引，不逐条解析整个更新/渲染流；原始流始终完整保存在磁盘。关联缓存的清理不删除或采样原始事件。

伤害回调发生在伤害应用前。本机枚举注明其参数为实体、伤害量、DamageFlag、DamageSource EntityRef、倒计时。记录的EntityRef是引擎传入该伤害请求的引用；唯一回调与血量变化相符时标unique_engine_callback_candidate，多个回调保留歧义，身份/房间不符则不关联。没有血量变化的请求不冒充受伤。不会把“附近最近实体”改称已确认伤害来源，也不截取其他回调的最终返回值。

## 完整性与恢复

每个回调有顺序号和已见/已写计数。更新时flush，伤害索引立即flush；结束时需游戏端关闭确认、seen==written和实际日志capture_end尾部一致，才标complete。编码/写入/注册失败、残缺尾部或结束未确认均标不完整并停止循环。已有非空日志拒绝覆盖。剩余空间低于512MiB时结束本局，不轮换或删除原始事件；外层原有1GiB开局门槛保留。

045使用独立room-test-runtime045，保留旧044的资源哈希；启动器按每局选定构建的runtime_directory加载，新增脚本也列入临时桥接备份/恢复路径。旧版仍可使用原room-test-runtime。默认依旧实时、不加速、不跳渲染、不注入时钟DLL，但逐条原始记录本身会增加开销，实际速度尚未测定。

## 验证和交付

33项相关Python/Lua检查及3项PowerShell5启动器检查通过。实际执行Lua5.3和本机JSON模块，逐个触发74个回调并额外触发1000次高频更新，序号连续、没有采样；覆盖64位标记、false/nil、userdata来源、移除引用、输入类型、同步桥接结束、关联歧义/身份错误/未应用请求、注册/编码/写入失败、低空间保护、完整尾部及历史摘要保存。路径配置用带撇号和中文的路径做Lua往返检查。

没有游戏实测、Computer Use、视觉验证或全量测试。枚举和离线执行不代替原生绑定验证；首次用户实测需检查capture_summary.complete及错误字段。
