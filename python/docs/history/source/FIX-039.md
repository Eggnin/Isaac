# 0.3.9 根据 038 实测记录修改战斗

依据：会话 `20261025-003454-691761` 共 12 局，7 局死亡、5 局卡住超时，12 局均有恢复成功记录。没有启动新游戏；没有 Computer Use、视觉验证或全量测试。

## 修改

- `planner.py` / `engine_search.py`：当前控制段的进展改看可达射击位置的导航距离，并在完整 4 帧控制段后比较，减少贴墙反向和原地推迟移动。原有硬碰撞、舒适距离、预警、退路优先级及采样范围保留。
- `engine_grid_attack.py` / `engine_app.py`：敌人所有射击路线不可达时，允许普通无特殊效果泪弹攻击射线上的第一个、原生已观察到的棕色便便。仅限未清房、目标对齐且在射程内；有 TNT、特殊泪弹、同伴或其他先行阻挡时不采用。不伪造地形清除、敌人生命或命中。
- `run_journal.py` / `combat_evidence.py`：便便原生状态或碰撞变化计为进展，另记 `can_attack_grid`，不冒充命中敌人。
- 退路末端探测不再计算未参与其评分的攻击目标成本，保留危险探测。固定快照、暖缓存、各 5 个样本的规划中位耗时从 50.72ms 降到 29.76ms；这不是游戏 FPS 或实际吞吐保证。
