# FIX-040：遮挡路线接近与泪弹继承校准

040 延续 039 的安全过滤。当前朝向与目标已对齐但射线被地形挡住、且全房间存在可达射击位时，规划器会在硬碰撞、警告、退路和出口安全之后优先缩短射击导航距离；此优先级会保持在同一目标上，直到出现可预测射击或射击路线不可达。它只会覆盖软舒适距离。

普通泪弹的继承校准改为最近有效样本的中位数。发射漂移使用快照中玩家的实际速度，而不是规划路径首点的预测速度。原来只要样本跨度超过 0.3 就把继承量归零，导致 run-0008 frame 6380 的泪弹被误判为直线上行。

## 冻结记录

- run-0003 的玩家在 `(124.2, 200.4)`，目标约在 `(119.9, 354.8)`；石块挡住下方直线射线，唯一几何射击位约为 `(70, 350)`。新排序的 60 步冻结模型绕过石块并走到 `(70.1, 317.5)`，导航距离从 `169.3` 降至 `32.7`。在记录的约 `86 ms` 延迟补偿下，再向射击位移动会被判为碰撞风险；模型没有开火。保留这一安全边界，不能据此宣称 run-0003 已清除。
- run-0008 frame 6380 的玩家速度为 `(2.145, 0.035)`，新生泪弹速度为 `(3.905, -10)`，单次观测对应继承系数约 `1.82`。包含该观测的最近 32 个有效样本中位数为 `1.247`、跨度约 `2.046`；039 会因跨度超过 `0.3` 将系数清零并选出“上”方向。040 的同帧离线回放不再报告预计命中。Hopper 状态切换仍使用当前速度线性外推，实际伤害结果未验证。
