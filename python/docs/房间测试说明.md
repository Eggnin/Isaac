# 房间测试

更新：2026-10-26。当前机制采集禁止改动游戏安装文件、游戏选项、存档、Mod 目录及 Steam 设置。以下房间测试是已有流程说明；本轮整理不运行这些入口。

`Start-Room-Tests.cmd` 经 `scripts/Start-Loop-Runs.ps1` 调用 `scripts/Run-Native-Session.ps1`。流程会临时复制 Lua 桥接到游戏 Mod 目录并改写 EnableMods，与当前边界冲突；后续须先具备符合边界的测试方式，或由用户明确更改边界，才能恢复此流程。`Start-Swarm-Tests.cmd` 同样调用 room-test，不能当成只读测试。

程序由 `dist/Latest-Isaac-Program.json` 选择，当前为 056，不能根据 runtime 目录里的 045 后缀判断版本。已有流程在原生开门后自动切房、死亡后重开；固定 Swarm 入口使用专项 XML。默认实时运行，不以加速或阻塞引擎换取通过。

双击根目录 Stop-Loop-Runs.cmd 或使用原有 F7 停止入口，等待保存和恢复完成。日志在 records/loop-runs。

045 起的捕获层逐条保存所有可用 Lua 回调，包含每实体每帧；后续 046～056 已有完整性和恢复记录，不再处于“等待首局”状态。完整日志、原生无伤与性能是不同验收项；056 两局仍有受伤和死亡。详见 [事件说明](EVENTS-045.md)、[当前问题](当前问题清单.md) 和 [056 报告](../records/validation/combat056-validation.json)。

离线验证可从 tests 运行 `../scripts/check-related.py` 并显式指定相关模块，或用 `scripts/replay-combat-sequence.py` 回放限定片段；两者不能替代原生闭环验证。
