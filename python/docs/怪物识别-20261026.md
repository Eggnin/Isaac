# 怪物识别：Wiki 名册与本机实体身份

## 名册来源与范围

`src/engine_monster_catalog.tsv` 收录了灰机 Wiki [怪物页](https://isaac.huijiwiki.com/wiki/%E6%80%AA%E7%89%A9)当前列出的 469 个唯一 `Type.Variant.SubType` 条目：337 个普通怪物、22 个迷你 Boss、110 个 Boss。文件中的中文名称和分类取自页面目录链接；相同名称但不同三元组仍保留为不同实体，例如流星锤的两个 SubType。

`src/engine_npc_entity_catalog.tsv` 在保留这 469 个 Wiki 身份的基础上，加入本机 J460 `entities2.xml` 中的 184 个补充 NPC 定义。它们包含 Boss 部件、火堆和环境 NPC，因此是本地实体目录扩充，不是 184 种新增怪物。

本机 `src/engine_enums.json` 是锁定 J460 游戏版本的 `EntityType` 枚举表。名册中每个条目的基础 Type 都能在该表找到；本机 `resources/scripts/enums.lua` 同样提供游戏脚本枚举来源。基础 Type 只用于版本和编号交叉核对，怪物中文名仍以 Wiki 的精确三元组映射为准。

## 快照识别

`src/engine_reader.py` 为 Type 10..999 的已观测实体生成 `npc_identity`：

- `key` 保留完整 `Type.Variant.SubType`。
- 命中 469 项 Wiki 名册时提供 `name_zh`、`category` 和 `resolution=wiki_exact`。
- 命中 653 项本机 NPC 目录时提供 `entity_config_key`、`entity_config_name`、`display_name`、`role` 和匹配依据；若运行时 SubType 不精确匹配，只在本机该 `Type.Variant` 唯一对应一个 EntityConfig 时回退。多个 SubType 配置不会猜测。
- 未命中本机目录时保留本机 `EntityType` 名称和原始 Variant/SubType。
- 快照的 `npc_identity_coverage` 分别统计 Wiki 精确命中、本机目录命中、唯一 Type/Variant 回退和补充 NPC 数量；它只描述当前快照。

覆盖率只针对当前快照里出现的实体，不等于当前房间或游戏版本中的全量怪物。Type 10..999 也可能包含非敌对 NPC，因此 `npc_identity` 表示实体身份，不承诺敌对状态。唯一 Type/Variant 回退只提供通用配置名称和角色线索，不证明未列 SubType 与配置 SubType 的 AI 攻击相同。模组实体、游戏版本差异或 Wiki 与本机目录未列出的三元组会显示数字身份和可用的基础 Type 名称。

## 边界

这一步只完成静态名册与只读快照的身份关联，没有改闪避、攻击、输入或引擎状态。识别依赖游戏读出的三元组准确；不能从尚未出现的实体推断其当前房间实例，也不能仅凭这份页面证明 Wiki 覆盖了所有游戏版本、模组和隐藏配置。未启动游戏验证本次新增字段。

此前用户提供的[贴吧《全小怪打法》](https://tieba.baidu.com/p/3225451919?pn=1)发表于 2014 年，正文说明部分怪物名由作者按外观或特性自取。它适合作为打法和别名参考，不替代与 J460 编号对照的 Wiki 名册。
