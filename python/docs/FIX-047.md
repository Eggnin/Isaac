# 047：空中弹幕与热炸弹

046 的新实机证据驱动本版；未修改游戏伤害、敌人、武器或生命规则，保持实时渲染与完整回调保存。

## 修复依据

- 046 会话 20261025-153821-e2ecd8 / run-0002：Monstro 弹幕 seed 115246800 在受伤前 frame 2305 的 collision_class=0、height=-50.14，下一观测变为 4 并死亡；frame 2305 的回调与 2306 的血量变化唯一关联。旧模型直接排除 class 0，预测为零碰撞。
- 同会话 run-0001：Little Horn 生成的 type 4 / variant 8 热炸弹 seed 197903016，在引信还剩 36 tick、collision_damage=0 时产生 DAMAGE_FIRE 请求。旧模型只在引信末尾预约爆炸，遗漏接触火焰。

资料对照：[BombVariant](https://wofsauge.github.io/IsaacDocs/rep/enums/BombVariant.html) 的 BOMB_HOT=8；[EntityProjectile](https://wofsauge.github.io/IsaacDocs/rep/EntityProjectile.html) 提供高度和下落字段；[ProjectileFlags](https://wofsauge.github.io/IsaacDocs/rep/enums/ProjectileFlags.html) 区分 CANT_HIT_PLAYER。精确 J460 激活阈值以原生时序继续校准，未从单个样本捏造通用阈值。

## 实现

- 正伤害的敌方 class-0 弹幕现在提前保守预约二维运动路径，保留运动拟合和弯曲预测。友方、无伤害、死亡、仅撞敌人以及 CANT_HIT_PLAYER 仍排除。
- 敌方有效热炸弹独立增加接触半径危险，与引信爆炸并存；己方热炸弹不增加敌方接触危险，但自伤爆炸仍保留。
- 决策记录增加 world_hypotheses，明确哪些区域是未来激活的保守假设，避免将假设称为当前真实碰撞。

## 验证

73 项相关离线检查通过，包含真实伤前帧、友方/敌人专属弹幕排除、己方炸弹与普通炸弹边界，以及原有事件、地形、瞄准和围堵检查。

31 帧原生片段固定在 tests/regression_data/combat047.json。两类伤害分别检查伤前 12/6/3/1 帧的完整决策栈，结果在 records/validation/native047-replay-0.4.6.json 与 native047-replay-0.4.7.json。弹幕案例伤前 12 帧改为提前上方避让；临伤帧不再全部显示安全。热炸弹出现后也产生了危险预测。固定轨迹回放不模拟改变输入后的敌人反馈，不能据此声称一定无伤。

047 原生有界结果记在 records/validation/combat047-validation.json，与 046 分开。固定源码 build/releases/047/source；程序 dist/IsaacExternalAssist047.exe。

单局 120 秒原生验证：7 次开门、5 次受伤，约 0.98x 游戏速度；379,273 条回调完整、恢复成功。来源分别是爆炸蜘蛛、Attack Fly、两次 Crazy Long Legs 和 Gemini。随机种子不同，不能与 046 直接比较受伤率。前两项新增保护在该随机局中没有取得同房型对照证据。

新证据继续驱动 048 的阶段追击和爆炸蜘蛛建模，不把本版称为无伤通过。

## 尚未完成

空中弹幕目前提前保守避让，未按精确高度裁剪危险窗口，可能导致绕行和更多规划开销。其他三种 046 近身伤害已有碰撞预测，需要继续研究更早撤离、惯性和输入延迟；攻击无进展、TNT 连锁清障及完整联机验证尚未解决。本版不代表所有怪物无伤。
